# Producto integrador de la Unidad 2

El estudiante desarrollará en **VS Code + Python** una solución básica de Visión Artificial orientada a un **problema real**, integrando, según la naturaleza del proyecto:

**Entrada audiovisual → preparación de datos → procesamiento → modelo de IA → reconocimiento/detección → PLN y/o voz → API o servicio externo → evaluación → optimización → resultado.**

El proyecto deberá incluir como mínimo:

1. Definición del problema y requerimientos.
2. Selección y preparación de imágenes o video.
3. Procesamiento de las entradas audiovisuales.
4. Implementación de una técnica de reconocimiento, clasificación o detección.
5. Uso de un modelo de IA o modelo preentrenado.
6. Aplicación de OCR cuando el problema requiera extracción de texto.
7. Integración de PLN y/o voz cuando sea pertinente.
8. Integración de una API o servicio externo cuando aporte funcionalidad al proyecto.
9. Evaluación de precisión, tiempo de procesamiento y calidad de resultados.
10. Identificación y corrección de errores.
11. Generación de resultados audiovisuales.
12. Documentación técnica.
13. Consideraciones de privacidad, seguridad y uso ético de la IA.
14. Presentación y demostración funcional del proyecto.

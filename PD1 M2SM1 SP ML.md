# Planeación Didáctica No. 1

**Módulo II:** Soluciona problemas con herramientas de Inteligencia Artificial
**Submódulo 1:** Soluciona problemas con Machine Learning
**Unidad de Aprendizaje 1:** Determina modelos de Machine Learning para solucionar problemas
**Semestre:** 3.er semestre de preparatoria
**Nivel:** Básico–Intermedio
**Entorno:** VS Code
**Lenguaje:** Python
**Duración:** 48 horas
**Semanas:** 8
**Horas por semana:** 6 horas
**Prácticas:** Demostrativa, guiada, supervisada y autónoma

### Distribución general de tiempos

| Fase           |       Tiempo |
| -------------- | -----------: |
| **Apertura**   |      8 horas |
| **Desarrollo** |     32 horas |
| **Cierre**     |      8 horas |
| **Total**      | **48 horas** |

---

## FASE 1. APERTURA — 8 HORAS

| ACTIVIDADES DE ENSEÑANZA – APRENDIZAJE                                                                                                                                                                                                                                                                                                                                                  | RECURSOS Y MATERIALES                                                                       |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| **1. Diagnóstico de conocimientos previos — 2 h.** El docente aplica un diagnóstico sobre programación Python, datos, algoritmos e Inteligencia Artificial. Los estudiantes responden individualmente y posteriormente participan en una lluvia de ideas sobre lo que conocen de IA y Machine Learning. **Estrategia:** evaluación diagnóstica y recuperación de conocimientos previos. | Computadoras, VS Code, Python, cuestionario diagnóstico, proyector, pizarrón, internet.     |
| **2. Introducción a IA, Machine Learning y Deep Learning — 2 h.** El docente presenta ejemplos cotidianos de Inteligencia Artificial y establece las diferencias entre IA, ML y Deep Learning. Los estudiantes elaboran un mapa conceptual y relacionan cada tecnología con aplicaciones reales. **Práctica demostrativa.**                                                             | Presentación, videos educativos, proyector, computadora, pizarrón, fichas de trabajo.       |
| **3. Tipos de aprendizaje automático — 2 h.** El docente explica aprendizaje supervisado, no supervisado e introducción al aprendizaje por refuerzo mediante ejemplos sencillos. Los estudiantes clasifican diferentes situaciones de acuerdo con el tipo de aprendizaje. **Estrategia:** aprendizaje basado en ejemplos.                                                               | Presentación, tarjetas de situaciones, videos, pizarrón, material digital.                  |
| **4. Identificación de problemas susceptibles de resolverse con ML — 2 h.** En equipos, los estudiantes analizan situaciones reales: predicción de precios, clasificación de correos, agrupamiento de clientes, reconocimiento de patrones, etc. Identifican posibles datos de entrada y resultados esperados. **Práctica guiada.**                                                     | Casos de estudio, hojas de trabajo, computadora, internet, repositorios de datos, pizarrón. |

---

## FASE 2. DESARROLLO — 32 HORAS

| ACTIVIDADES DE ENSEÑANZA – APRENDIZAJE                                                                                                                                                                                                                                                               | RECURSOS Y MATERIALES                                                          |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| **5. Instalación y configuración de Python y VS Code — 3 h.** El docente demuestra la configuración del entorno para Machine Learning. Los estudiantes realizan la instalación/configuración de Python, extensiones de VS Code y verificación del intérprete. **Práctica demostrativa y guiada.**    | Computadoras, Windows, Python, VS Code, extensión Python, internet, proyector. |
| **6. Creación de entornos virtuales — 2 h.** El docente explica la importancia del aislamiento de dependencias. Los estudiantes crean un entorno virtual y realizan su activación desde la terminal de VS Code. **Práctica guiada.**                                                                 | VS Code, terminal PowerShell, Python, documentación técnica.                   |
| **7. Instalación y administración de bibliotecas — 2 h.** Los estudiantes instalan y prueban bibliotecas básicas para ML: NumPy, Pandas, Matplotlib y Scikit-learn. Verifican versiones y realizan una pequeña prueba de importación. **Práctica supervisada.**                                      | VS Code, terminal, pip, NumPy, Pandas, Matplotlib, Scikit-learn.               |
| **8. Introducción a Jupyter Notebook en VS Code — 2 h.** El docente demuestra la creación y ejecución de notebooks. Los estudiantes crean un notebook, ejecutan código Python y documentan los resultados utilizando Markdown. **Práctica guiada.**                                                  | VS Code, extensión Jupyter, Python, notebook, proyector.                       |
| **9. Fundamentos de Python para ML: variables, tipos, operadores y expresiones — 3 h.** Se desarrollan ejercicios contextualizados con datos numéricos. Los estudiantes crean variables y realizan operaciones necesarias para el procesamiento inicial de datos. **Práctica guiada y supervisada.** | VS Code, Python, Jupyter Notebook, ejercicios, computadora.                    |
| **10. Estructuras de decisión y repetición — 3 h.** El docente presenta `if`, `elif`, `else`, `for` y `while`. Los estudiantes resuelven problemas relacionados con clasificación de datos y procesamiento de registros. **Práctica supervisada.**                                                   | VS Code, Python, Jupyter Notebook, ejercicios prácticos.                       |
| **11. Estructuras de datos y funciones — 3 h.** Los estudiantes trabajan con listas, tuplas, diccionarios, conjuntos y funciones. Construyen pequeñas funciones para procesar datos. **Práctica guiada y supervisada.**                                                                              | VS Code, Python, Jupyter Notebook, conjuntos de datos pequeños.                |
| **12. Conceptos fundamentales de datos — 3 h.** El docente explica dato, característica (*feature*), variable objetivo (*target*), datos de entrada y salida. Los estudiantes analizan un conjunto de datos e identifican sus variables. **Aprendizaje basado en problemas.**                        | Datasets CSV, Pandas, Jupyter Notebook, VS Code, proyector.                    |
| **13. Datos numéricos y categóricos — 2 h.** Los estudiantes identifican variables numéricas y categóricas, distinguen variables relevantes y analizan posibles problemas de calidad de datos. **Práctica supervisada.**                                                                             | Datasets, Pandas, Jupyter Notebook, hojas de análisis.                         |
| **14. Identificación y planteamiento de problemas de ML — 3 h.** Cada equipo selecciona un problema real y determina contexto, usuarios, requerimientos técnicos, datos necesarios, variables relevantes y resultado esperado. **Estrategia:** aprendizaje basado en proyectos.                      | Formato de análisis, computadora, internet, repositorios de datos, datasets.   |
| **15. Fuentes y repositorios de datos — 2 h.** El docente muestra fuentes de datos y criterios básicos para seleccionar información pertinente. Los estudiantes localizan un dataset apropiado para su problema y justifican su selección. **Práctica autónoma supervisada.**                        | Internet, repositorios públicos, archivos CSV, navegador, VS Code.             |
| **16. Modelos de aprendizaje supervisado — 2 h.** Introducción a clasificación, regresión lineal, regresión logística, árboles de decisión y KNN. Los estudiantes comparan conceptualmente los modelos y relacionan cada uno con diferentes tipos de problemas.                                      | Presentación, diagramas, Scikit-learn, ejemplos, proyector.                    |
| **17. Modelos de aprendizaje no supervisado — 2 h.** Se explica clustering y K-Means. Los estudiantes analizan ejemplos de agrupamiento y determinan cuándo es conveniente utilizar aprendizaje no supervisado. **Práctica demostrativa y guiada.**                                                  | VS Code, Jupyter Notebook, Scikit-learn, Matplotlib, datasets.                 |

## FASE 3. CIERRE — 8 HORAS

| ACTIVIDADES DE ENSEÑANZA – APRENDIZAJE                                                                                                                                                                                                                                         | RECURSOS Y MATERIALES                                                                     |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------- |
| **18. Comparación y selección de modelos — 2 h.** Los equipos comparan modelos supervisados y no supervisados considerando tipo de problema, características de los datos, objetivo y resultados esperados. Elaboran una matriz de decisión. **Práctica supervisada.**         | Computadora, VS Code, Jupyter Notebook, matriz comparativa, datasets.                     |
| **19. Diseño de propuesta de solución — 2 h.** Cada equipo desarrolla una propuesta de solución con ML: contexto, problema, datos, variables, modelo seleccionado, proceso y resultado esperado. **Práctica autónoma.**                                                        | Plantilla de proyecto, computadora, VS Code, Jupyter Notebook, internet.                  |
| **20. Representación gráfica del proceso de solución — 1 h.** Los estudiantes elaboran un diagrama que represente el flujo: problema → datos → preparación → modelo → entrenamiento → predicción/agrupamiento → evaluación → resultado.                                        | Diagramador, PowerPoint/Canva/draw.io, computadora, proyector.                            |
| **21. Ética, privacidad y responsabilidad en el uso de datos — 1 h.** El docente presenta situaciones relacionadas con privacidad, sesgos, uso responsable de información y toma de decisiones automatizada. Los estudiantes analizan un caso y proponen medidas responsables. | Casos de estudio, presentación, videos, internet, guía de análisis.                       |
| **22. Presentación del proyecto integrador — 1 h.** Cada equipo presenta su propuesta, explica el problema, los datos y la selección del modelo. Los compañeros realizan preguntas y retroalimentación. **Práctica autónoma.**                                                 | Computadora, proyector, presentación digital, diagrama, notebook.                         |
| **23. Evaluación final y reflexión — 1 h.** Se aplica una evaluación teórico-práctica. Los estudiantes realizan una autoevaluación y reflexión sobre los aprendizajes alcanzados, dificultades y aplicaciones futuras del Machine Learning.                                    | Instrumento de evaluación, cuestionario, rúbrica, computadora, formato de autoevaluación. |

**Total: 48 horas**

# Evidencias de aprendizaje e instrumentos de evaluación

| Evidencias de aprendizaje                             | Características                                                              | Instrumento de evaluación / indicador                                                                                               |
| ----------------------------------------------------- | ---------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| **1. Diagnóstico inicial**                            | Identifica conocimientos previos sobre Python, IA, datos y ML.               | **Cuestionario diagnóstico.** Indicador: reconoce conceptos básicos relacionados con IA y programación.                             |
| **2. Mapa conceptual de IA, ML y Deep Learning**      | Diferencia los conceptos y establece relaciones entre ellos.                 | **Lista de cotejo.** Indicador: distingue correctamente IA, ML y Deep Learning.                                                     |
| **3. Clasificación de tipos de aprendizaje**          | Clasifica situaciones como supervisadas, no supervisadas o de refuerzo.      | **Lista de cotejo.** Indicador: identifica el tipo de aprendizaje adecuado para cada situación.                                     |
| **4. Análisis de problemas reales**                   | Identifica problema, datos de entrada y resultado esperado.                  | **Guía de observación.** Indicador: relaciona un problema real con una posible solución mediante ML.                                |
| **5. Entorno Python–VS Code configurado**             | Python, VS Code y extensiones funcionando correctamente.                     | **Lista de cotejo técnica.** Indicador: configura correctamente el entorno de desarrollo.                                           |
| **6. Entorno virtual funcional**                      | Crea, activa y utiliza un entorno virtual.                                   | **Guía de observación.** Indicador: administra correctamente un entorno virtual de Python.                                          |
| **7. Bibliotecas instaladas**                         | NumPy, Pandas, Matplotlib y Scikit-learn instaladas y verificadas.           | **Lista de cotejo.** Indicador: instala, importa y verifica bibliotecas requeridas.                                                 |
| **8. Jupyter Notebook**                               | Notebook ejecutable con código y documentación Markdown.                     | **Rúbrica de práctica.** Indicador: utiliza Jupyter Notebook dentro de VS Code.                                                     |
| **9. Ejercicios de Python: variables y operadores**   | Resuelve problemas utilizando variables, tipos y operadores.                 | **Lista de ejercicios.** Indicador: aplica correctamente variables, tipos y operadores.                                             |
| **10. Programa con decisiones y ciclos**              | Soluciona problemas utilizando estructuras condicionales y repetitivas.      | **Rúbrica de código.** Indicador: implementa correctamente `if`, `elif`, `else`, `for` y `while`.                                   |
| **11. Programa con estructuras de datos y funciones** | Utiliza listas, tuplas, diccionarios, conjuntos y funciones.                 | **Lista de cotejo de código.** Indicador: organiza y procesa información mediante estructuras y funciones.                          |
| **12. Análisis de dataset**                           | Identifica características, variable objetivo, entradas y salidas.           | **Guía de análisis.** Indicador: identifica correctamente `features`, `target` y tipos de datos.                                    |
| **13. Clasificación de variables**                    | Distingue datos numéricos y categóricos y detecta variables relevantes.      | **Lista de cotejo.** Indicador: clasifica correctamente las variables del conjunto de datos.                                        |
| **14. Planteamiento del problema de ML**              | Documento con contexto, problema, usuarios, requerimientos y variables.      | **Rúbrica de planteamiento.** Indicador: define un problema viable para Machine Learning.                                           |
| **15. Dataset seleccionado**                          | Fuente de datos justificada de acuerdo con el problema.                      | **Rúbrica de selección de datos.** Indicador: selecciona una fuente pertinente, suficiente y relacionada con el problema.           |
| **16. Cuadro comparativo de modelos**                 | Compara clasificación, regresión, árboles, KNN y otros modelos.              | **Lista de cotejo.** Indicador: relaciona modelos con la naturaleza del problema.                                                   |
| **17. Práctica de clustering/K-Means**                | Ejecuta o interpreta un agrupamiento básico de datos.                        | **Guía de observación y rúbrica práctica.** Indicador: explica el propósito del clustering y el funcionamiento básico de K-Means.   |
| **18. Matriz de selección del modelo**                | Justifica el modelo seleccionado mediante criterios técnicos.                | **Rúbrica analítica.** Indicador: selecciona un modelo coherente con el problema y los datos.                                       |
| **19. Propuesta de solución con ML**                  | Integra problema, datos, variables, modelo y proceso de solución.            | **Rúbrica de proyecto.** Indicador: diseña una propuesta de solución técnicamente coherente.                                        |
| **20. Diagrama del proceso de ML**                    | Representa gráficamente las etapas de una solución.                          | **Lista de cotejo.** Indicador: representa ordenadamente el flujo de trabajo de Machine Learning.                                   |
| **21. Análisis ético**                                | Identifica riesgos de privacidad, sesgo y uso irresponsable de datos.        | **Rúbrica de estudio de caso.** Indicador: propone medidas para el uso ético y responsable de datos.                                |
| **22. Presentación del proyecto**                     | Expone la propuesta, argumenta la selección del modelo y responde preguntas. | **Rúbrica de exposición.** Indicadores: dominio conceptual, claridad, argumentación, comunicación y trabajo colaborativo.           |
| **23. Evaluación final y reflexión**                  | Demuestra conocimientos teóricos y prácticos adquiridos durante la unidad.   | **Evaluación teórico-práctica + autoevaluación.** Indicador: integra los conocimientos fundamentales para determinar modelos de ML. |

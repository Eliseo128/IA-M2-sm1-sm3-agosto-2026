# Planeación Didáctica No. 1

## Módulo II: Soluciona problemas con herramientas de Inteligencia Artificial

Submódulo 1: Soluciona problemas con lenguaje natural

## Propósito de la planeación

Que el estudiante comprenda los fundamentos del Procesamiento de Lenguaje Natural (PLN), configure correctamente el entorno de desarrollo en Python y VS Code, desarrolle programas básicos para manipular texto y aplique técnicas iniciales de PLN mediante prácticas de laboratorio, empleando estrategias de aprendizaje activo para resolver problemas multidisciplinarios de manera ética y responsable.

# Contenidos que se desarrollan

### Bloque 1. Introducción al Procesamiento de Lenguaje Natural

1.1 Concepto de lenguaje natural 1.2 Concepto de Procesamiento de Lenguaje Natural 1.3 Inteligencia Artificial y PLN 1.4 Aplicaciones del PLN en la vida cotidiana 1.5 Aplicaciones del PLN en diferentes áreas 1.6 Ventajas y limitaciones del PLN 1.7 Ética y responsabilidad en el uso del lenguaje y los datos

### Bloque 2. Entorno de desarrollo para PLN

2.1 Instalación y configuración de Python 2.2 Configuración de VS Code 2.3 Creación de entornos virtuales 2.4 Instalación de bibliotecas para PLN 2.5 Ejecución de programas Python 2.6 Organización de un proyecto básico de PLN

### Bloque 3. Fundamentos de Python para PLN

3.1 Variables y tipos de datos 3.2 Cadenas de caracteres 3.3 Operadores y expresiones 3.4 Estructuras condicionales 3.5 Estructuras repetitivas 3.6 Listas, tuplas y diccionarios 3.7 Funciones 3.8 Manejo básico de archivos de texto

### Bloque 4. Texto y datos lingüísticos

4.1 Caracteres, palabras y oraciones 4.2 Estructura de un documento de texto 4.3 Corpus y conjuntos de datos textuales 4.4 Texto estructurado y no estructurado 4.5 Fuentes de información textual 4.6 Importación de archivos de texto 4.7 Codificación de caracteres

### Bloque 5. Técnicas básicas de PLN

5.1 Tokenización 5.2 Tokenización de palabras 5.3 Tokenización de oraciones 5.4 Eliminación de palabras vacías 5.5 Stemming 5.6 Lematización 5.7 Comparación entre stemming y lematización 5.8 Limpieza básica de texto

### Bloque 6. Análisis sintáctico y semántico

6.1 Concepto de sintaxis 6.2 Concepto de semántica 6.3 Partes del discurso 6.4 Identificación de sustantivos, verbos y adjetivos 6.5 Relaciones entre palabras 6.6 Significado y contexto 6.7 Ambigüedad del lenguaje natural

### Bloque 7. Representación de texto

7.1 Características de los textos 7.2 Frecuencia de palabras 7.3 Bolsa de palabras 7.4 Frecuencia de términos 7.5 TF-IDF 7.6 Representación numérica del lenguaje 7.7 Introducción a embeddings

### Bloque 8. PLN y Machine Learning

8.1 Relación entre PLN y Machine Learning 8.2 Clasificación de textos 8.3 Datos de entrenamiento y prueba 8.4 Características de entrada 8.5 Modelos básicos de clasificación 8.6 Entrenamiento de un clasificador sencillo 8.7 Predicción de categorías 8.8 Evaluación básica de resultados

9.1 NumPy 9.2 Pandas 9.3 NLTK 9.4 spaCy 9.5 Scikit-learn 9.6 Bibliotecas especializadas 9.7 Selección de bibliotecas según el problema

# Evidencias de aprendizaje e instrumentos de evaluación

# Indicadores generales de logro de la unidad

* Reconoce los fundamentos del Procesamiento de Lenguaje Natural y su relación con la Inteligencia Artificial.

* Configura correctamente un entorno de desarrollo utilizando Python y Visual Studio Code.

* Desarrolla programas básicos en Python para el procesamiento de cadenas y archivos de texto.

* Aplica técnicas de tokenización, eliminación de palabras vacías, stemming y lematización mediante bibliotecas especializadas.

* Analiza textos utilizando frecuencia de palabras, Bag of Words y TF-IDF.

* Implementa un clasificador básico de textos empleando herramientas de Machine Learning.

* Selecciona técnicas de PLN adecuadas para resolver un problema multidisciplinario.

* Documenta y comunica los resultados obtenidos con responsabilidad ética en el tratamiento de datos lingüísticos.

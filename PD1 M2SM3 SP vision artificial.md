# Planeación Didáctica No. 1

**Módulo II:** Soluciona problemas con herramientas de Inteligencia Artificial
**Submódulo 3:** Soluciona problemas con Visión Artificial
**Unidad de Aprendizaje 1:** Identifica procesos de extracción y procesamiento de contenido audiovisual para Visión Artificial
**Semestre:** 3.er semestre de preparatoria
**Nivel:** Básico–Intermedio
**Entorno:** VS Code
**Lenguaje:** Python
**Duración:** 40 horas
**Semanas:** 8
**Horas por semana:** 5 horas
**Prácticas de laboratorio:** Demostrativa, guiada, supervisada y autónoma

## Producto integrador de la Unidad 1

El estudiante desarrollará en **VS Code + Python + OpenCV** una aplicación básica de Visión Artificial que integre el siguiente flujo:

**Entrada audiovisual → lectura de imagen/video → exploración → procesamiento → extracción o segmentación → resultado → almacenamiento → interpretación.**

El proyecto deberá incluir como mínimo:

1. Estructura organizada de archivos.
2. Lectura de una imagen o video.
3. Obtención de propiedades básicas.
4. Al menos **dos técnicas de procesamiento**.
5. Una técnica de extracción de características o segmentación.
6. Visualización del resultado.
7. Almacenamiento del resultado procesado.
8. Documentación del procedimiento.
9. Consideraciones básicas de privacidad y uso responsable de imágenes.
10. Presentación y demostración funcional.
